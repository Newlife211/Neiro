# Нейросфера — компания из ИИ-агентов

В репозитории две части:

| Папка | Что это |
|---|---|
| `server/`, `deploy/` | **Боевая версия.** Сервер, где ИИ-агенты на Claude круглосуточно выполняют реальные задачи: пишут документы, переписываются с клиентами, создают ссылки на оплату Stripe и ЮKassa, тратят деньги в пределах ваших лимитов. Всё крупное и необратимое ждёт вашего «да» в пульте или в Telegram |
| `simulator/` | **Симулятор.** Пиксельный «живой офис» в одном файле `index.html`, деньги там игровые. Нужен для наглядности и обучения |

## Боевая версия — коротко
- **Направление на старте:** ИИ-продукты и SaaS. Цепочка: идея → анализ → решение директора → MVP → запуск → оплаты.
- **Деньги:** клиенты платят через Stripe (ЕС) и ЮKassa (РФ) прямо на ваши счета. Сервер только создаёт ссылки на оплату и ведёт учёт; каждая оплата проверяется (подпись Stripe, перепроверка через API ЮKassa).
- **Контроль:**
  - агенты сами тратят только в пределах лимитов на одну трату, день и месяц;
  - подписки, возвраты, деплой, смена цен, договоры и всё сверх лимита — только после вашего подтверждения;
  - кнопка «СТОП» мгновенно останавливает все внешние действия;
  - отдельный потолок на расходы Claude API.
- **Пульт директора** (веб): обзор денег, решения, задачи, проекты, штат, документы, учёт, лента событий.
- **Технологическая разведка:** каждое утро отдел собирает GitHub, Hacker News и блоги ИИ-компаний, оценивает пользу и присылает дайджест; новинки внедряются только через пилот с проверкой безопасности и вашим решением.
- **Финансы:** курсы ЕЦБ и ЦБ РФ; под каждую одобренную трату — виртуальная карта Revolut ровно на сумму; выписки Revolut и Paysera сверяются с учётом автоматически.
- **Telegram:** бот — канал связи с компанией: поручения обычным сообщением, вопросы сотрудников с ответом кнопкой или реплаем, решения кнопками, совещания с протоколом, лента событий. Мини-приложение «Кабинет директора» — рабочий стол от первого лица, где каждый предмет открывает раздел управления, и выход в офис: изометрический 3D-вид сверху, где видно, кто над чем работает прямо сейчас.
- **Без внешних зависимостей:** Node 22, встроенный SQLite, Docker + Caddy (HTTPS).

## Разработка

```bash
cd server
npm test        # 47 тестов: политика, деньги, вебхуки, карты, сверка, разведка, агенты, пульт, Telegram, кабинет
npm run check   # проверка настроек .env
npm start       # локальный запуск, пульт на http://localhost:8080
```
