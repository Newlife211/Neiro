# Нейросфера — живой офис ИИ-агентов

Интерактивная симуляция компании из ИИ-агентов: пиксельный офис, где у каждого сотрудника есть должность, инструкция, KPI, настроение, мысли и задачи. Директор (пользователь) нанимает и увольняет, ставит задачи, проводит совещания, утверждает проекты, доступы и стратегии.

> Деньги, выручка и сделки — **симуляция**. Реальный доход появится, когда агентов подключат к настоящим платежам, рекламе и площадкам (см. «Следующий шаг»).

## Запуск

Это один самодостаточный файл `index.html`, без сборки и зависимостей.

- Локально: откройте `index.html` в браузере. Офис работает на встроенных сценариях поведения.
- Как артефакт Claude на claude.ai: становятся доступны ИИ-мозг (агенты думают и говорят через Claude) и живые данные Nansen для крипто-аналитики.

Состояние хранится в `localStorage` браузера (ключ `neurosfera-v1`). Кнопка ⟲ сбрасывает офис к первому дню.

## Что внутри

- **56 агентов** в 20 отделах:
  - основные: Администрация, Аналитика, R&D, Маркетинг, Продажи, Клиенты, Качество, IT, Техподдержка, Бухгалтерия, Юристы, HR, Служба безопасности;
  - крыло крипто-трейдинга из 6 отделов;
  - Продуктовая команда ИИ.
- **Директор по развитию** (вкладка «Развитие»):
  - раз в 2 дня готовит отчёт: финансы, воронка проектов, нагрузка и KPI отделов, раздел «Куда идём»;
  - даёт практические рекомендации, которые запускаются в работу одной кнопкой.
- **Планёрки и совещания.** Планёрки отделов проходят ежедневно. Совещания созывает директор: задачи с дедлайнами, премии и штрафы, объяснительные.
- **Доступы.** Агенты подают заявки на сервисы и коннекторы. Вкладки: Заявки / Одобренные / Подключённые / Каталог, с инструкциями по подключению. Главный критерий выбора — полная автоматизация.
- **Документы секретаря:** Планы (масштабирование, стратегия развития), Напоминания, Приказы.
- **Карточки отделов.** Можно закрыть отдел с перераспределением функций и отправкой сотрудников на стажировку.
- **Трейдинг.** Бумажная торговля с лимитами риска и независимым риск-менеджментом.
- **Настройки** рабочего дня.
