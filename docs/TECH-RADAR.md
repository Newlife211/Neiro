# Технологическая разведка

Отдел каждый день ищет новые технологии, сервисы, репозитории, скиллы и MCP-серверы, оценивает их пользу для «Нейросферы» и ведёт внедрения.

## Распорядок
- **07:00 — сбор, бесплатно, без ИИ:**
  - GitHub — новые репозитории за неделю по темам `llm`, `ai-agents`, `mcp`, `claude`, `rag`, `agentic-ai`, набирающие звёзды;
  - Hacker News — самые обсуждаемые истории за сутки по ИИ и технологиям;
  - блоги и ленты: Anthropic, OpenAI, Hugging Face, GitHub Changelog, Simon Willison, Latent Space.
- **Дальше — разбор.** Виктор оценивает до 40 самых заметных находок: «неинтересно», «наблюдать» или «пилот», плюс польза 0–10. За подробностями идёт сам или поручает коллегам. У отдела есть веб-поиск Claude и чтение страниц и README.
- **Дайджест в Telegram:** 5–10 главных событий дня и что из этого полезно нам. Полная версия — в пульте, вкладка «Технологии».
- **По понедельникам — технологический радар:** «Внедрять», «Пробовать», «Изучать», «Не трогать». Для уже внедрённого — подтверждение эффекта цифрами.

## Путь любой новинки в компанию
1. **Предложение.** Что внедряем, польза в цифрах, стоимость, риски, план пилота на 1–2 недели, какой отдел внедряет.
2. **Ваше решение** — кнопка «Запустить пилот» в Telegram или в пульте.
3. **Проверка безопасности.** Служба безопасности проверяет лицензию, автора и живость проекта, нужные доступы и данные, риски утечек и промпт-инъекций, зависимости. Если проверка не пройдена, внедрение блокируется и вы получаете причину.
4. **Пилот** в отделе-исполнителе: тестовые данные, траты только через лимиты, эффект в цифрах.
5. **Ваше решение о внедрении** по итогам пилота. Если «Внедрить», отдел встраивает новинку в работу и обновляет регламент.

Агенты **ничего не устанавливают на боевой сервер сами**. Новый код, пакеты и интеграции попадают в систему только через разработчика после пилота.

## Настройки (`deploy/.env`)
| Переменная | Что | По умолчанию |
|---|---|---|
| `RADAR_FEEDS` | Свои RSS/Atom-ленты через запятую | список выше |
| `RADAR_GITHUB_TOPICS` | Темы GitHub | llm, ai-agents, mcp, claude, rag, agentic-ai |
| `GITHUB_TOKEN` | Токен GitHub (только чтение публичных данных) — снимает лимит запросов | — |
| `RADAR_HN_MIN_POINTS` | Порог популярности на Hacker News | 80 |
| `RADAR_DAILY_ITEMS` | Сколько находок разбирать в день | 40 |
| `RADAR_WEB_SEARCH` | Веб-поиск Claude для исследовательских отделов (0 — выключить) | включён |
| `PRICE_WEB_SEARCH` | Цена веб-поиска за 1000 запросов, USD (сверьте на anthropic.com/pricing) | 10 |

Стоимость: сбор бесплатный. Разбор — это одна задача руководителя в день плюс точечные поручения. Всё укладывается в общий дневной бюджет на Claude API (`LIMIT_LLM_DAILY`).
