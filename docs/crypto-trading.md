# Направление «Крипто-трейдинг» (обзор)

Обновлено: 2026-11-17

- Аналитика, отделы, команда и регламент: https://claude.ai/artifact/P9JWDETLbByLRxRTgjLLhA
- В офисе: новое крыло из 6 отделов, 16 агентов, вкладка «Трейдинг».

## Ключевые решения
- ИИ ищет идеи, тестирует стратегии, анализирует рынок и следит за риском. Сделки исполняет бот (Freqtrade / Hummingbot) по проверенным правилам.
- CRO (Сергей Дорохов) независим, подчиняется директору и может остановить всю торговлю.
- Путь стратегии: идея → бэктест → проверка риска → бумажная торговля 30+ дней (в офисе — 5 игровых дней) → решение директора → реальная торговля малой суммой.
- Лимиты на старте: 1% риска на сделку, 2% дневного убытка, 10% просадки, плечо 1×.
- Ключи бирж — без права вывода, с белым списком IP, на субаккаунте, в хранилище доступов.
