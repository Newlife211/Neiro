# Telegram: связь с компанией и кабинет директора

## Что умеет бот
- **Поручения:** просто напишите сообщение, и COO получит его как поручение. Отчёт придёт сюда же.
- **Вопросы сотрудников:** если агенту нужно ваше решение, он пишет вам. Ответьте кнопкой-вариантом или реплаем текстом, и ответ уйдёт сотруднику отдельной задачей. Лимит — 3 вопроса в день на сотрудника, чтобы вас не дёргали по мелочам.
- **Решения:** траты сверх лимита, проекты, пилоты технологий приходят с кнопками «Одобрить / Отклонить».
- **Маркетинг:** планы тестов спроса с кнопкой «Одобрить бюджет», отчёты с решением «масштабировать / ещё тест / закрыть», `/marketing` — сводка. СТОП ставит рекламу на паузу.
- **Совещания:** `/meeting повестка`. Руководители готовят доклады, COO сводит протокол с решениями и поручениями, протокол приходит в чат.
- **Что происходит:**
  - `/feed all` — вся лента компании пачками раз в минуту;
  - `/feed important` (по умолчанию) — только важное;
  - `/feed off` — только решения.
- **Утро и вечер:** отчёт директора по развитию, дайджест технологической разведки, итоги дня.
- **Команды:** `/cabinet`, `/status`, `/approvals`, `/questions`, `/meeting`, `/marketing`, `/feed`, `/stop`, `/resume`.

Бот принимает команды и нажатия **только из вашего чата**. Сообщения из любых других чатов игнорируются.

## Кабинет директора (мини-приложение)
Кнопка **«Кабинет»** слева от поля ввода открывает ваш рабочий стол с видом от первого лица. Каждый предмет на столе — раздел управления:

| Предмет | Раздел |
|---|---|
| Монитор | Обзор: деньги, задачи, проекты, банк, лента событий |
| Лоток «Входящие» | Решения: траты, проекты, пилоты, ручные действия |
| Смартфон | Вопросы сотрудников (варианты-кнопки и ответ текстом) |
| Блокнот с ручкой | Поручение любому сотруднику, список ваших поручений и отчёты |
| Календарь | Совещания: повестка, участники, ход докладов, протоколы |
| Папки | Документы компании |
| Глобус | Технологическая разведка: находки, дайджесты, пилоты |
| Калькулятор | Деньги: выручка, расходы, остатки, сверка банка |
| Доска на стене | Команда: кто в штате, сколько стоит |
| Красная кнопка | СТОП всех внешних действий (с подтверждением) |

### Выход в офис
Дверь справа в кабинете или кнопка **«🚪 В офис»** вверху открывают офис сверху в изометрическом 3D-виде. Он показывает **реальное состояние компании** и обновляется каждые 8 секунд:
- **за столом с горящим монитором и зелёным облачком «⌨ …»** — сотрудник работает, в облачке задача, над которой он думает прямо сейчас;
- **«⏳ в очереди: N»** — у сотрудника есть задачи, ждёт своей очереди;
- **на кухне с ☕** — свободен;
- **в переговорной с 📣** — участник идущего совещания, над столом видна повестка;
- **«👑 Вы»** — ваш кабинет; звёздочка над головой — руководитель отдела.

Офис листается пальцем, щипок меняет масштаб, кнопка ⤢ показывает весь офис. Нажмите на сотрудника — откроется карточка: что делает сейчас, очередь, сделано за сегодня, расход Claude, последние задачи с результатами и кнопка «Дать поручение». Нажмите на отдел — откроется его состав и кнопка поручения отделу.

Внизу — быстрые кнопки: Решения, Поручить, Совещание, Вопросы, СТОП. Окно за спиной монитора меняется по времени суток, часы на стене идут.

**Безопасность.** Кабинет проверяет подпись Telegram (initData) на каждом запросе: открыть его может только аккаунт с ID из `TELEGRAM_DIRECTOR_CHAT_ID`. Ссылка, переданная кому-то другому, ничего не откроет.

## Подключение
1. Бот уже создан у @BotFather. Его токен впишите в `deploy/.env` на сервере:
   ```
   TELEGRAM_BOT_TOKEN=токен_от_BotFather
   ```
   В git, в код и в переписку токен не вставляйте. Если токен где-то засветился, в @BotFather выполните `/revoke`, получите новый и замените его в `.env`.
2. Узнайте свой ID: напишите @userinfobot, он ответит числом. Впишите `TELEGRAM_DIRECTOR_CHAT_ID=это_число`.
3. Кабинету нужен https-адрес: `PUBLIC_URL=https://ваш-домен` (тот же, что для пульта).
4. Выполните `docker compose up -d` и напишите боту `/start`. Кнопка «Кабинет» появится сама: сервер настраивает её при запуске.
5. Необязательно: в @BotFather → `/setdescription` и `/setuserpic` для оформления.

Кабинет можно открыть и в обычном браузере по адресу `https://ваш-домен/tg` — вход по `DIRECTOR_TOKEN`.
